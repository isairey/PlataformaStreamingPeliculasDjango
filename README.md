# 🌌 Acerca del proyecto

**MoviStream** es una plataforma multimedia online enfocada en la exploración y búsqueda de películas mediante una interfaz moderna y responsive.

La aplicación fue desarrollada utilizando **Python + Django**, integrando scraping web y contenido multimedia dinámico para ofrecer información actualizada de películas.

El proyecto permite:

- 🎬 Buscar películas
- 📖 Ver descripciones multimedia
- 🌐 Explorar contenido online
- ⚡ Navegación rápida
- 📱 Diseño responsive
- 🔍 Búsqueda dinámica

# ⚡ Instalación

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaStreamingPeliculasDjango.git
```

---

## 2️⃣ Entrar al proyecto

```bash
cd PlataformaStreamingPeliculasDjango
```

---

## 3️⃣ Instalar dependencias

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Ejecutar servidor

```bash
python manage.py runserver
```
